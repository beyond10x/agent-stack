# agent-stack

The beyond10x agent stack: from model providers through the model call, harness, meta-harness and
agent runtime up to applications. Scroll through it at https://beyond10x.github.io/agent-stack/.

The page is generated from [`stack.yaml`](stack.yaml). To build and view it locally:

```console
task preview
```

Then open http://127.0.0.1:4317/agent-stack/.
